        Sobre o projeto

        Objetivo: aplicação Web responsiva e utilizável offline para cadastrar peças de roupa e sugerir looks com base em regras de combinação.

        Integrantes

        • Ana Lígia de Souza Vale — @Analigiadsv
        • Bruna Michelly Dias Martins — @b-diaxs
        • Camila Brozeguine Dernei — @CamilaBrozeguine
        • Fernanda Santana Leandro — @fernandasl1010-jpg

        Tecnologias

        HTML, CSS e JavaScript (módulos ES), localStorage, fetch, Web Share API, Service Worker e Cache API.

        Créditos

        As peças são representadas por emojis Unicode. Não há imagens ou ícones externos.

        Projeto de finalidade exclusivamente acadêmica (Introdução ao Desenvolvimento para Dispositivos Móveis, Centro Universitário Afya Ji-Paraná). Todos os dados ficam apenas no seu navegador.
